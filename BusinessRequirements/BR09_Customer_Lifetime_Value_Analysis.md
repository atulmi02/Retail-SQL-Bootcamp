# BR #09 - Customer Lifetime Value (CLV) Analysis

## Business Requirement

The Sales Director wants to identify the company's most valuable customers based on their lifetime purchasing behaviour.

The report should calculate each customer's lifetime value by measuring total completed sales, purchasing frequency, and average order value for the calendar year 2025.

---

## Grain of Report

One row represents the annual sales performance of a single customer for the calendar year 2025, including total sales, total orders, average order value (AOV), contribution to the company's total sales, and customer rank.

## Business Requirement

- Which customer generated highest sales?
- How many completed orders where generated by each customer?
- What is Average Order Value of each customer?
- What was contribution percentage to company sales?
- Customer Life Value  = Average Order Value * Purchase Frequency * Customer Lifespan

## Production Considerations

- Filter data as early as possible.
- Aggregate before applying window functions.
- Use NULLIF() to prevent divide-by-zero errors.
- Round only presentation values.
- Keep window functions in the same CTE whenever possible.
- Avoid unnecessary joins.
- Ensure indexes support filtering and grouping columns.
